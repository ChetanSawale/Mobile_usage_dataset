📊 5G Network Deployment Analysis – Power BI Dashboard

📌 Project Overview
This project presents an interactive Power BI dashboard analyzing global 5G network deployment data.
The dashboard visualizes how different telecom operators are deploying 5G NR (New Radio) across cities worldwide and provides insights into deployment patterns, operator presence, and geographic distribution.
The dataset contains 5000+ records including telecom operators, city locations, deployment status, and geographical coordinates.
This project demonstrates data visualization, dashboard design, and analytical insights using Power BI.

📂 Dataset Information
The dataset includes the following attributes:

Column	Description
Operator	Telecom company deploying the network
City_Name	City where 5G deployment exists
Deployment_Type	Type of network deployment (e.g., 5G NR)
Status	Deployment status (e.g., Commercial Availability)
Latitude	Geographic latitude of the city
Longitude	Geographic longitude of the city


📊 Dashboard Features
The Power BI dashboard includes the following visualizations:
📍 Geographical Deployment Mapping using latitude and longitude
📈 Deployment distribution across operators
🌍 City-wise 5G availability analysis
📊 Deployment type analysis
📌 Interactive filtering and slicing
📉 Comparative insights between operators and regions


🔍 Key Insights
Some insights obtained from the dashboard:
Multiple telecom operators are actively deploying 5G NR networks globally
Major cities show higher concentration of commercial 5G availability
Geographic visualization helps identify regional deployment patterns
Some operators dominate specific regions or cities
